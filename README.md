# Data-Analysis-on-CSV-Files
Sales Data Analysis using Python, Pandas, and Matplotlib. The project demonstrates CSV file handling, data cleaning, sales calculations, product and category analysis, and data visualization. It identifies total revenue, quantity sold, best-performing products, and generates charts for better understanding of sales performance.

# Sales Data Analysis

## Project Overview
This project focuses on analyzing sales data using **Python, Pandas, and Matplotlib**. It demonstrates how to handle CSV files, perform data analysis, calculate sales-related metrics, and create visualizations to understand business performance.
The project is designed to demonstrate basic data analysis techniques and practical use of Python libraries.

## Objectives
The main objectives of this project are:
* Create and manage sales data using Pandas.
* Handle CSV files for storing and reading data.
* Check and analyze dataset information.
* Identify missing values.
* Calculate total sales and quantity sold.
* Analyze sales based on products.
* Analyze sales based on categories.
* Identify the best-performing product.
* Compare product sales using charts.
* Visualize sales information using Matplotlib.

## Project Features
### CSV File Handling
The project demonstrates how to create, save, and load CSV files using Pandas.
```python
df.to_csv("sales_data.csv", index=False)
```

The CSV file is then loaded for further analysis:
```python
df = pd.read_csv("sales_data.csv")
```

### Data Analysis
The project performs several operations, including:
* Viewing the first few records.
* Checking rows and columns.
* Checking column names.
* Checking missing values.
* Calculating sales.
* Grouping data by product.
* Grouping data by category.
* Finding the highest-performing product.

### Sales Calculation
Sales are calculated using the quantity and price of each product.

```python
df["Sales"] = df["Quantity"] * df["Price"]
```

### Data Visualization
Matplotlib is used to generate visual charts that make the analysis easier to understand.
The project creates:
1. **Sales by Product**
2. **Sales by Category**
3. **Quantity Sold by Product**
